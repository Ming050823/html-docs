## 資料夾規則

- 所有 HTML 文件統一存放在 `docs/html/`。
- 每份文件使用獨立、英文小寫與連字號的資料夾，例如 `docs/html/my-document/index.html`。
- 圖片、CSS、JavaScript、data 等相依檔案放在同一份文件的資料夾內，維持相對路徑。
- `docs/index.html` 是網站首頁目錄；新增文件時，複製一張 card 並更新網址、標題與文件數量。
- GitHub Pages 發布來源：`main` 分支的 `/docs`。
- 在 GitHub 網頁開啟目標資料夾，再選 Add file → Upload files；提交到 main 後自動重新發布。

## 新增文件範例

新增 `docs/html/my-document/index.html` 後，閱讀網址為：
`https://Ming050823.github.io/html-docs/html/my-document/`

若文件只有單一 HTML，也建議命名成 index.html 放進專屬資料夾，讓網址維持一致。
