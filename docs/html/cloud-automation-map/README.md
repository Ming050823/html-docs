這是原始雲端版說明頁：自動化寫好後交給 GitHub Actions、Vercel／Netlify 或 Trigger.dev 代管，24 小時運作。頁面支援中／英切換，並可複製完整 Prompt 原文。

對照本機版：https://github.com/Ming050823/local-automation-map

## 把 HTML 上傳進這個儲存庫

1. 打開 https://github.com/Ming050823/cloud-automation-map/upload/main
2. 把 `index.html`（把 `cloud-automation-map.html` 改名即可）拖進頁面
3. 選 **Commit directly to the `main` branch**，按 **Commit changes**

上傳後可用預覽網址：

https://htmlpreview.github.io/?https://github.com/Ming050823/cloud-automation-map/blob/main/index.html

## 開啟 GitHub Pages

1. https://github.com/Ming050823/cloud-automation-map/settings/pages
2. Source 選 **Deploy from a branch**
3. Branch 選 `main`，資料夾選 `/ (root)`，按 Save

網址：https://ming050823.github.io/cloud-automation-map/
