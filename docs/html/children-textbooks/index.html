27. 第 27 題

當時間 $t = 7$ 秒時，繩子上波的波前端與波尾端位置分別為？

正解：(B)

手部振動一次後停止（歷時 2 秒），波以 $v = 0.5\lambda/\text{s}$ 向右傳播。
$t = 7$ s 時，波前端已傳播 $7 \times 0.5 = 3.5\lambda$，波尾端為 $5 \times 0.5 = 2.5\lambda$。

28. 第 28 題

當時間 $t = 7$ 秒時，繩子上正在振動的區域長度為？

正解：(A)

波包長度 = 波前端 - 波尾端 = $3.5\lambda - 2.5\lambda = 1\lambda$。
因手部只振動一次，波包長度固定為 $1\lambda$。
