2. 高階工作流

2. High-level workflow

規劃 → 執行 → 部署監控。可省略、可拉長、高度迭代。

Plan → execute → deploy and monitor. Steps can be skipped or stretched.

Planning

Planning

研究、實驗、理解程式碼 → spec → 執行計畫。檢視假設、安全、過度設計。

Brainstorm, spec, execution plan. Check assumptions, security, overengineering.

Execution

Execution

Agent 建、測、驗證。平衡自主與人工監督。

Build, test, verify. Balance autonomy and oversight.

Deploy & monitor

Deploy & monitor

CI/CD 或人工閘門部署；agent 看 log 並改進。

Deploy, then watch logs and apply improvements.

3. 五項核心能力

3. Five core skills

3.1 Directing the workflow 指揮工作流

3.1 Directing the workflow

決定每步人力／agent 時間、何時回退、spec 寫多細、如何拆成可驗證步驟。

Decide human vs agent effort, when to iterate back, spec depth, and verifiable decomposition.

3.2 Enabling agent autonomy 讓 agent 能自主

3.2 Enabling agent autonomy

選自主層級、管 context、並行、權限與閘門。

Choose autonomy, manage context, run parallel agents, set safe permissions.

3.3 Reviewing the work 審查產出

3.3 Reviewing the work

行為／功能驗證、user flow、eval、agentic review。測試由你指定。

Behavioral and functional checks, flows, evals, agentic review. You own the tests.

3.4 Customizing environment 客製環境

3.4 Customizing the environment

AGENTS.md / CLAUDE.md、skills、hooks、MCP。累積 learnings，清技術債。

Standing context, skills, hooks, MCP. Accumulate learnings; clear agent debt.

3.5 Coding agent foundations 心智模型

3.5 Coding agent foundations

看懂 search、context、tool、subagent、harness，辨認過度設計、沒驗證就停、破壞資料等失敗。

Understand search, context, tools, subagents, harness, and failure modes.

長跑燒掉海量 token 的實用價值目前被放大。有效用法多半高度迭代，並依賴判斷力介入。
Very long-horizon runs are often oversold. Skilled iterative intervention usually wins.

5. 可直接套用的日常流程

5. Daily loop

  1. Planning。 Plan mode 或 /plan → spec、分步計畫、每步驗證。人只審假設、安全、過度設計。
  2. Execution。 小改互動；大改 goal + 測試迴圈。權限夠用不無限。
  3. Review。 換角色審或交叉審。測試由你指定。
  4. Customize。 反復精正寫進 md / skill / hook。
  5. Monitor。 部署後 MCP 或 CI hook 看 log，再走 plan → patch → verify。
  1. Planning. Plan mode or /plan → spec, phases, verifiers. Humans check assumptions and security only.
  2. Execution. Interactive on small edits; goal + tests on larger work. Enough permission, not unlimited.
  3. Review. Fresh session or cross-review. You specify tests.
  4. Customize. Promote corrections into markdown, a skill, or a hook.
  5. Monitor. Logs via MCP or CI; re-enter plan → patch → verify.
起手式：先寫好 AGENTS.md（Claude 加 CLAUDE.md）的測試指令與禁區。
Start with test commands and off-limits paths in AGENTS.md (and CLAUDE.md).
